# 📦 .NET 9 Web API + MongoDB CRUD Example

A simple CRUD (Create, Read, Update, Delete) REST API built with **.NET 9** and **MongoDB**.

---

## 🚀 Features

- 🔄 Full CRUD operations
- 📦 MongoDB integration using `MongoDB.Driver`
- 🧭 MongoDB Compass support
- 💡 Clean, minimal codebase

---

## 🧰 Tech Stack

- [.NET 9](https://dotnet.microsoft.com/)
- [MongoDB](https://www.mongodb.com/)
- [MongoDB.Driver](https://www.nuget.org/packages/MongoDB.Driver)
- [MongoDB Compass (optional)](https://www.mongodb.com/products/compass)

---

## 📥 Prerequisites

- .NET 9 SDK
- MongoDB installed and running locally
- MongoDB Compass (optional for GUI)
